# Ajrumiyyah Nahw Study Guide

Interactive single-page study guide for **Matn al-Ājurrūmiyyah** (al-Ajrumiyyah)
in Arabic *naḥw*, by Ibn Ājurrūm aṣ-Ṣanhājī (d. 723 AH).

**Scope:** from *Bāb al-Kalām* through the four *Tawābiʿ* — Naʿt, ʿAṭf,
Tawkīd, and Badal (stops before *al-Manṣūbāt*).

Each chapter gives the original *matn* in Arabic, an English rendering, a
structured breakdown, and worked examples. Includes reference tables,
flashcards, a matching game, and a quiz. Fully self-contained and works
offline — the only external dependency is Google Fonts over HTTPS.

Open `index.html` in any browser, or serve it via GitHub Pages.
